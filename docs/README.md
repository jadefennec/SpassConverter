# SPASS Converter – GitHub Pages

This folder is used for [GitHub Pages](https://pages.github.com/).

## Enable GitHub Pages

1. Open: https://github.com/stanley-projects/SpassConverter/settings/pages
2. Under **Build and deployment**, set **Source** to: `Deploy from a branch`
3. Set **Branch** to: `master` and folder to `/docs`
4. Click **Save**
5. Wait 1–2 minutes for the site to build

## Your Privacy Policy URL

After enabling Pages, your URL will be:

**https://stanley-projects.github.io/SpassConverter/**

Use this in Play Console for the Privacy Policy link.

## Security

The `docs/` folder contains only static HTML. No scripts, no external resources, no credentials or sensitive data. Safe to publish.
